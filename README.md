## Code extraction note

The recording shows CSS snippets in small, scrolling code panes. The visible selectors, keyframe names, colors, and principal values have been transcribed where legible. Some lines are clipped or too small to read precisely; those parts have been reconstructed into valid CSS that reproduces the displayed animation. This is a faithful visual/functional recreation, not a byte-for-byte copy of the unseen original source.

## Run

1. Extract the ZIP.
2. Open `index.html` in Chrome, Firefox, Safari, or Edge.
3. Scroll to view all ten loaders.
4. Scroll within each right-side code panel to read its CSS snippet.

No JavaScript, npm, framework, external asset, or internet connection is required.
